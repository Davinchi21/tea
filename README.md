# 🍃 Чайная Лавка

Сайт-витрина для магазина чая с прямыми поставками из Китая, Индии, Японии и Цейлона.

## Возможности

- Каталог чая с ценами
- Корзина с localStorage
- Карусель отзывов
- Адаптивный дизайн (мобильное меню-гамбургер)
- Заказ через WhatsApp
- Анимированные счётчики
- Подписка на новости
- Toast-уведомления

## Технологии

HTML, CSS (flexbox/grid, адаптив), vanilla JS (ES6+)

## Локальный запуск

Просто открой `index.html` в браузере. Никаких сборщиков не нужно.

## Структура

```
assets/
  css/
    main.css    — все стили
index.html       — главная страница
```
